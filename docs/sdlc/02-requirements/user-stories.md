# 2.6 User Stories

Mfumo wa standard: As a [role], I want [action], so that [benefit].

## Patient

| ID | Story |
|---|---|
| US-PAT-001 | As a patient, I want to record my medication schedule so that I can remember when to take my medication. |
| US-PAT-002 | As a patient, I want to record symptoms and pain so that I can track how I feel over time. |
| US-PAT-003 | As a patient, I want to view my health timeline so that I can understand my health history at a glance. |
| US-PAT-004 | As a patient, I want to request blood so that I can get help when I need it. |
| US-PAT-005 | As a patient, I want to request emergency assistance so that I can get help quickly. |
| US-PAT-006 | As a patient, I want to manage consent for my medical records so that only authorized people can see them. |
| US-PAT-007 | As a patient, I want to receive reminders for medication and appointments so that I do not miss them. |
| US-PAT-008 | As a patient, I want to learn about sickle cell and pain management so that I can better manage my condition. |

## Caregiver

| ID | Story |
|---|---|
| US-CAR-001 | As a caregiver, I want to connect to a patient with their permission so that I can see the information I need to help. |
| US-CAR-002 | As a caregiver, I want to receive emergency notifications so that I can act quickly. |

## Blood Donor

| ID | Story |
|---|---|
| US-BLD-001 | As a blood donor, I want to receive relevant blood requests so that I can help patients when I am available. |
| US-BLD-002 | As a blood donor, I want to set my availability so that I only get requests when I can help. |

## Doctor

| ID | Story |
|---|---|
| US-DOC-001 | As a verified doctor, I want to access authorized patient information so that I can provide appropriate clinical support. |
| US-DOC-002 | As a doctor, I want to be verified by the admin so that patients can trust my identity. |

## Admin

| ID | Story |
|---|---|
| US-ADM-001 | As an administrator, I want to verify healthcare professionals so that only legitimate professionals can use doctor-specific functionality. |
| US-ADM-002 | As an administrator, I want to moderate community content so that the community stays safe. |
| US-ADM-003 | As an administrator, I want reports and audit logs so that I can monitor system health and security. |

## Financial Donor

| ID | Story |
|---|---|
| US-SUP-001 | As a financial donor, I want to see verified fundraising campaigns so that I can contribute with confidence. |
