# 2.1 Stakeholder Requirements

Mfumo utawahudumia stakeholders hawa:

| Stakeholder | Mahitaji makuu |
|---|---|
| Patient | Kusimamia afya: medication, appointments, blood requests, emergency, education |
| Caregiver/Family | Kumsaidia patient kwa taarifa alizopewa ruhusa |
| Doctor | Kuona taarifa za wagonjwa walioidhinisha access, kutoa ushauri na clinical information |
| Blood Donor | Kujisajili, kuweka blood group/location/availability na kupokea requests |
| Financial Donor | Kuchangia kampeni na kuona donation history |
| Hospital/Clinic | Kushiriki katika workflows zinazohusiana na patient/blood/emergency |
| Admin | Verification, moderation, users, campaigns, blood requests, reports na security |
| System | Notifications, matching, audit, analytics na automation |

## Priorities fallback

Stakeholder mahitaji yataorodheshwa kwa priorities wakati wa implementation planning:

- **P0** — critical path: login/register, medication, blood requests, emergency.
- **P1** — core: appointments, medical records, doctor verification, donations.
- **P2** — supporting: community, education, AI assistance, analytics.
