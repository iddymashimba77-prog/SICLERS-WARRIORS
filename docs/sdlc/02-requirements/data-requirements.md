# 2.8 Data Requirements

Mfumo utahitaji data za msingi kwa maeneo haya:

## Identity & Access
- User (account, roles, verification status)
- Authentication (sessions, tokens, password reset)
- Role / Permission assignments

## Clinical / Patient data
- Patient profile
- Medical profile (diagnosis, genotype, baseline)
- Medical records
- Medications & schedules
- Appointments
- Symptoms / Pain events
- Health timeline

## People network
- Caregiver (links to patient, permissions)
- Doctor (professional info, verification, specialty)
- Hospital / Clinic
- Blood donor (blood group, location, availability, last donation)

## Blood network
- Blood requests
- Blood matches
- Donor responses

## Emergency
- Emergency requests
- Severity classification
- Response tracking / audit trail

## Fundraising & payments
- Campaigns
- Donations
- Payment transactions
- Receipts

## Community
- Community posts
- Comments / reactions
- Reports / moderation records

## Communication
- Conversations
- Participants
- Messages

## Engagement
- Notifications
- Notification preferences
- Health education content

## Consent & compliance
- Consent grants (scope, duration, revocation)
- Audit logs

> **Kumbuka:** Hapa kuna data requirements pekee. Database design (tables, columns, relationships) itaingia Stage 3 — System Design (ERD).
