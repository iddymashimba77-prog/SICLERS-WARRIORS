## 2. What was delivered

**New surfaces/capabilities**
- `AUTH_PASSWORD_VALIDATORS` now enforced at register, password-reset-confirm
  and password-change (previously `create_user`-only), plus length/denial rule.
- Full session revocation: logout blacklists refresh; rotation denylists the old
  refresh; password change and password reset **denylist every outstanding
  refresh (outstand-all) and kill in-flight access via the JWT rev-claim**;
  suspension flips `is_active` so live sessions die immediately.
- `AuthThrottle` (scope `auth`, hashed identifier, 10/min production budget;
  unlimited in test) wired into the six auth endpoints.
- Payment webhook secrets **fail closed** in a `production` env (per-provider
  secret required; shared/dev placeholder refused); production settings refuse
  the placeholder `DJANGO_SECRET_KEY` at import time.
- Refund money-movement: single `transaction.atomic` + `select_for_update` +
  under-lock rechecks; MFA step-up boundary enforced.
- Community: `moderation_reason` moderation-only; comment threads of HIDDEN
  posts 404 to members; reaction-type whitelist.
- Blood: donor-facing request list = public subset (`PublicBloodRequestSerializer`);
  COMPLETED donation events require an ACCEPTED/FULFILLED `BloodMatch`.
- Emergency: `phone_verified` is no longer client-settable.
- OpenAPI schema + Swagger UI gated to audit readers (silent 404) outside DEBUG.
- Correlation-id sanitisation (CR/LF replaced with 16-hex; valid ids kept).
- `SecurityEvent` on reset uses the real `PASSWORD_RESET` kind (the previous
  ad-hoc event type was invalid).
- New `security_hardening` app — cross-app, endpoint-level regression suite (29).

## 5. Risks & carry-over (no silent divergence)

1. **AI-trends uid oracle — NOT FIXED (LOW, accepted).** Partial 404/403
   differential is a legacy **approved** test contract; a fix attempt regressed
   it and was reverted. Compensations: 160-bit random uids, rate limiting,
   denied-attempt auditing. Tracked for a formal contract-change re-roll.
2. **Audit immutability — NOT FIXED (MEDIUM, documented).** ORM is append-only
   (zero update/delete callers); DB-level `NO UPDATE/DELETE` grant goes into the
   production provisioning runbook at deploy time.
3. **CVE/OSV scan — NOT AVAILABLE.** `pip-audit`/`safety` not installed; `pip
   check` clean as the available substitute; CI lockfile scan is the tracked
   follow-up.
4. **MFA codes — NOT AVAILABLE.** Mechanism (TOTP) not built; the 4.16
   `MfaPolicy` boundary already blocks every privileged surface, refund now
   included. Tracked.
5. **`token_blacklist` INSTALLED_APPS = schema change.** Two tables ship with
   the bundled app's own migrations. **Deploy must run `migrate`.** Not run
   against Postgres this stage (ephemeral SQLite + suite prove the paths).
