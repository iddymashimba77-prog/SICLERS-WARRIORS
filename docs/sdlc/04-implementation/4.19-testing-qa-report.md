# 4.19 — Testing & QA Integration Report

> Stage 4.19 closes the *verification* side of the SDLC gate: a dedicated
> **gatekeeper QA suite** living in its own `backend/qa` app, an expanded
> **frontend (Flutter) contract suite**, a **regression for a real bug found
> by the new suite**, a runnable stage gate (`stage419_gate.py`), and — as in
> every stage since 4.1 — **zero changes committed** and **Postgres untouched**
> (every run uses the ephemeral in-memory SQLite profile).

---

## 1. Methodology

| Dimension | Approach |
|---|---|
| Profile | `config.settings.ephemeral_test` — in-memory SQLite, seeded migrations, pristine DB per run. Postgres (`sickle_cell`) is **never** reached by any 4.19 run. |
| Backend injector | `qa/qa_helpers.py` — `JsonAPIClient` (JSON+auth-credential convenience), `orm_user`, log-in helper, facility/first-notification probes. |
| Coverage style | Behavioural + adversarial: happy-path journeys, role-gated access, **IDOR attempts**, PII containment, throttling/idempotency, signed webhooks, deprecated-surface 404s. |
| Scoping rule | Tests assert against **real serializers, real views, real permissions, real throttles** — no mocks of the backend under test; LocMem throttle state is reset per test class (`cache.clear()`). |
| Frontend injector | `MockClient` (`package:http/testing`) + real repositories + real pages/controllers; offline simulation via a failable `http.BaseClient`. |
| Evidence | `stage419_gate.py` re-runs the exact commands below on every invocation. |

### 2.2 Real bug found & fixed (delivered with its regression)

`emergencies/views.py` raised **`KeyError` → HTTP 500** whenever a SOS request
omitted `description`. Fixed to `data.get("description", "")` and guarded by
`qa.tests_e2e` so the ORIGINAL 500 reproduces on the old code and the fixed
path returns 201.

## 4. Notes & carry-over

- LocMem throttle state persists across test classes while user PKs reset per
  class; the helper contract is **`cache.clear()` per class** that creates
  SOS/donations. Tests comply.
- Nothing new to deploy: the `qa` app is test-only (`PROJECT_APPS`) with an
  empty `management/commands` tree; only the dependency-light `http`/`flutter_test`
  toolchain and the gate script ship.
- Postgres remains the production target; every backing-runner flake noted above
  applies to ephemeral LocMem/SQLite only.
